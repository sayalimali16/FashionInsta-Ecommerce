# FashionInsta-Ecommerce
FashionInsta : E-commerce Website having user and admin Panel
A full-stack E-Commerce Website with general online shopping functionalities.
Users can register, login, browse products, search, manage their cart, and place orders.
The project includes a separate Admin Panel for managing products, users, categories, and orders.
Designed with a user-friendly and responsive interface for a smooth shopping experience.
